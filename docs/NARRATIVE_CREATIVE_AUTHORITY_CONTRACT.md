# Delegated creative narrative authority — contract v1 / request schema 8

Accepted typed intents are canonical adjudication inputs; human declarations own intent; native receipts own outcomes.

The owner's new policy delegates ordinary invention to the GM: local or camera-only places/people, atmosphere, observed oddities, leads, attributed rumors, NPC self-knowledge, motives, ordinary dialogue and attempted behavior. An older fact is not required. Decorative prose does not need a canon row. Model-produced text/claims/safe labels are never a native effect receipt.

Hard boundaries: PC/proxy voluntary control; private disclosures and character/NPC knowledge; committed canon and protected identity; native dice, damage, Armor/Stress/Hope, costs, custody/inventory, contested access/travel, death and binding effects. Native canon is not written by narrative units. The wider fiction policy does not grant unearned combat stats or supernatural capabilities.

Version 8 is a request, not trusted prose. One audience-isolated writer emits bounded independently meaningful `narrative_units` and meaningful `fiction_delta` identities in the same call. Native code independently binds source, owner/control revision, session, scene, audience, camera/actual position and exact payload hash. Units are individually held or established, not cut apart with sentence regexes. Raw combined-GM drafts remain GM-private. Native outcomes ignore the model text and render the real native receipt.

Identity creation reuses native world identity preflight, minor-NPC validators, world-authoring policy, reference and simulation services. New NPCs initially receive no adversary template, powers, resources or privileged knowledge. A new world-camera place or NPC never moves a PC or proves PC witness. PC aliases/surnames/possessives are conservative protection tripwires, not entity interest scoring.

`drafted_private`, `accepted_established`, `queued_to_audience`, `acknowledged_to_audience`, and `retired_from_context` remain distinct. Establishment is GM world memory, not listener knowledge. Failed/uncertain delivery cannot disclose memory or replay effects. NPC cognition needs its existing own witness/delivery/inference evidence. Rumor/testimony is never upgraded to objective observation by a model label.

Flags default OFF: master `narrative_authority` requires existing `playable_narration` + `scene_continuity`; subordinate `narrative_memory`, `narrative_camera`, `narrative_encounters`, `narrative_completeness` require the master; `narrative_salience` additionally requires memory. Parent disablement cascades safely; no production flag JSON is edited by tests. Existing version 7 behavior is preserved when the master is OFF.

Residual risk is explicit: native provenance, constrained scope, isolated inputs, typed effect boundaries and finite agency tripwires do **not** prove arbitrary-English semantics or detect every indirect implication, private coincidence, or canon contradiction. This is delegated GM-authorship risk, not permission to mint effects. Suspicious protected assertions are held at unit boundaries with private diagnostics; independent valid fiction/native actions remain available. No extra model judge or unconditional second provider request.
