## Rough text-session examples
These are planning estimates, not bills.

Assume **120 actual GM responses**, each averaging:
- 4,000 uncached input tokens
- 350 output tokens

Approximate main-GM cost:
- gpt-6-luna: **$0.07**
- gpt-6.1-sol: **$1.38**
- gpt-6-astra: **$6.90**

An Active-mode router might evaluate ~400 player messages. At a few hundred tokens each on Luna, that generally adds only a few cents.

Longer narration, larger retrieved context, repeated rule references, and high-volume play raise cost. Prompt caching can reduce repeated-input cost when applicable.

A local calculator is included:
```bash
cd bot
node scripts/cost-estimate.mjs 120 4000 350
```
