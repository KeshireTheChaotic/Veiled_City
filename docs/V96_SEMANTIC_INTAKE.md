Accepted typed intents are canonical adjudication inputs; human declarations own intent; native receipts own outcomes.

## Production paths

Party and private message intake use `routeGameplayIntake`: the complete immutable input survives as one unresolved ledger span. No recall regex consumes an unknown action or alters conjunctions/offsets. Existing exact native slash commands, consumed-source proofs and historical ledger readers are unchanged. Natural recall is interpreted with the existing scoped combined GM context; `/vc-intel discover` remains the zero-model private read-only lookup.

`GMService.shouldRespond` uses its existing semantic router for authenticated unmentioned messages, including idioms, reflection and chatter. Explicit OOC and mention-only controls remain free. Unassigned assisted chatter without conversation context remains free. The router decides engagement, never consent, costs or outcomes. A provider failure admits authenticated input conservatively to the combined turn instead of recognizing only English invitation phrases. This rare fallback may engage chatter; no state effect follows merely from engagement.

After exact-source intent recovery, a source-grounded immediate typed proposal requires meaningful engagement. Conditional/quoted/reported candidates are not promoted by a lexical verb/need. Full native acceptance, source/owner/audience/dependency/receipt checks still follow; a response-duty proposal is not an accepted effect. A rules channel uses the same semantic router in explicit read-only rules scope, not an English keyword detector. Rules answers still use their existing source-grounded service. No per-clause model calls were added.
