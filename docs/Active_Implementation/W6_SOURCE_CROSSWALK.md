A public descriptor is neither player observation nor publication authority. Private source ancestry remains private; player-facing notices use the common owner/audience proof and durable outbox. HR13 fully defines Break the Pattern: three distinct established original-event details, identified and deliberately disrupted by the same authenticated PC through ordinary adjudication, -2 Difficulty for the rest of the current scene, once per actor/scene, no automatic roll/additional cost. Its missing progress/event adapter is implementation work, not missing owner policy.

HR11 fixes remaining/marked HP and Bad Future's remaining HP <=3. HR03 v2 fixes Local Mesh's qualified same-zone allied Signal implementation; it does not prove Route Around's actual powered endpoint or arbitrary pairwise Close range.

HR01, HR03 v2 and existing supported descriptors remain outside the 137. Older HR03/HR06/HR07 entries are not a reason to recategorize qualified Local Mesh/Flashbang/Command the Blood as new review occurrences. HR05 Signal-Touched and HR09 Blackout are signal-card contracts outside this 153-occurrence adversary/environment catalog; they do not increase this crosswalk's counts.

The rightmost column separates genuinely absent printed numbers/timing/branch mechanics from runtime fictional facts or missing implementation. **None** means no new general owner-policy answer is needed; actual source/target/choice evidence is still mandatory. An explicit current ruling can supply contextual facts/terms where the text delegates discretion, but cannot silently add a universal DC, duration, damage type, price or tick cadence. Environments already have printed template Difficulty fields; omission of an inline reaction DC is not absence of that field, and using it still needs an applicable sourced default.

`compileNativeFeatureRuleContexts`, `nativeFeatureRuleContext`, `nativeFeatureReviewContract`, printed source tables, family labels and held diagnostics are source-only noneffect context. They do not satisfy any producer → receipt → current/saved reader → entitled output path.
