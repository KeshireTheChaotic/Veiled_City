# V9.5 — optional supervised real-player / real-model pilot protocol

**Not automatically authorized.** The v9.5 implementation plan itself authorizes no API usage, live Discord contact or production data access. ChatGPT mock narrative tests and network-denied Node fixtures do not bill the user's API account; actual bot calls to OpenAI do. Separate user approval is required before any live-model, Discord staging or spend.

## Preconditions

- v9.5 offline source gates PASS; independent v9.4 P0 consent, HP and output guards remain green; current committed SHA pinned, no dirty unreconciled code. GM abort/pause controls and private pending/recovery readouts tested.
- Four explicitly consenting testers, independent character owners, moderator/GM present. Dedicated staging guild and synthetic/cloned *anonymized* database, separate permissions/channels, no private production campaign import or secret transcripts. Every PvP participant understands lethal-risk-only current damage mode, with harmless narrative as the safe alternative.
- Explicit model/version, request/tokens/$ ceilings; hard kill/stop switch; capture API token count/cost, timeouts, retries, errors; get prior consent for any private transcript retention and prefer privacy-safe aggregates. Never copy `.env` credentials into logs or prompt.
- Verify staging slash command schema and optional voice route only after distinct owner approval. Snapshot/rollback, freeze production and disable automatic paid retries outside limits.

## Metrics and acceptance

- **Zero tolerance:** unsupported player-owned action/speech/emotion, private-information exposure, model-only PC HP/Stress/Armor/Hope changes, duplicate native dice or applied effects, PvP Hope gain, banked/forgotten Fear, defender reaction Fear move, unnoticed consent escalation, unowned death choice, unverified outbox resend.
- Track model/token spend, GM-latency p50/p95, queue lag, proportion of player turns with useful narrative responses, proportion stuck in neutral/quarantine, stale UI recoveries, manual GM operations per Fear, held consequences, NPC/PC coherence, dropouts/refusals and consent clarity. Record human-rated story relevance/proportionality with explicit criteria; an automated phrase match alone is not quality evidence.
- Live pilot 'PASS' requires all staged scenarios actually observed with sign-off from moderator and participating players, no unresolved P0 and no hidden incomplete Fear/continuation/recovery; anything not exercised is marked NOT TESTED. Distinguish preexisting blocking behavior from new v9.5 regressions.
