# Semantic language robustness: remaining gaps

Audit date: 2026-10-15. Branch: `codex/semantic-language-robustness`. Independently verified HEAD: `6de758c95f94fa5895f9d14bc05970922b050b44`; clean tree before this documentation task. Runtime version10.2.0/schema460.

Accepted typed intents are canonical adjudication inputs; human declarations own intent; native receipts own outcomes.

## Scope and conclusion

S0–S6 repaired important production paths, but did **not** eliminate semantic false holds, competing read models, or coverage blind spots. A passing security suite is not proof that ordinary narration is consistently expressive. The appropriate next step is targeted repairs and separation of obsolete producers from required native readers—not disabling narrative authority wholesale.

This audit found both **over-strict language checks** and **insufficiently scoped narrative composition**. Prioritize scene locality, entitled NPC recall, contradictory answers, whole-turn false rejection and per-task completeness before removing their surrounding compatibility machinery. No new mechanical-effect adapter is proposed here.

This is an audit and future implementation plan, not a runtime repair. No source/test/registry/configuration changes, production access, live Discord, paid provider requests, push or deployment occurred. A fake writer's success is not evidence of unrestricted live-model understanding. No production P0 damage/privacy exploit is claimed from these fixtures.

Evidence labels:

- **Reproduced:** reached existing production functions using deterministic providers and disposable SQLite; actual prepared/queued payloads or native context were inspected.
- **Source-confirmed:** reachable implementation limitation, not a claim of observed live incidence.
- **Unresolved:** requires more evidence or an explicit product/authority decision.

### Important interpretation limits

The remote-utterance result establishes an output-locality gap, not that a remote NPC acquired knowledge: dialogue capture independently requires hearing. The private-party-label result establishes mistagging, not a demonstrated public leak. Richer role/utterance classifications must not become model-issued agency or disclosure permissions. Some conservative false holds will remain unless a safely isolated expressive route can be demonstrated; do not promise universal semantic detection.

The original12:10 arrival-only live cause remains **unresolved** without that turn's authoring/receipt evidence. None of these new synthetic findings retroactively diagnoses it.
