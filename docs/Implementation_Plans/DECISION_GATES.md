# Blockers and mandatory owner questions

**Ask before new narrative or autonomy restrictions**, including prose length caps, dialogue templates, bans on minor invention, restrictions on NPC or faction independent activity, enforced fixed GM pacing, mandatory human approval of ordinary fiction, hard creative schema reductions, model downgrade that diminishes creative quality, or other new restrictions on the intended AI GM. Record current code, reason, proposal, less restrictive alternative and a precise question in the feature ledger. Hold only the restrictive change pending answer; continue safe independent work.

**Unfinished tests are not reasons to spend Codex tokens monitoring:** record `RUNNING / UNQUALIFIED`, work independently and retrieve the terminal result only once it is naturally needed; see [TEST_EXECUTION_NO_POLL.md](TEST_EXECUTION_NO_POLL.md). A test that takes longer than anticipated is not automatically a critical blocker.

**Local noncritical holds:** one missing rule or source, unsupported feature, optional cache miss, unproven optimization, provider credentials for optional benchmarks, draft/document drift, owner decision about new creative limits. Do not fabricate; make progress elsewhere.

**Critical:** no trustworthy source/worktree; unavoidable state corruption, PC consent/ownership leak, private data leak, fabricated dice/effects, irreversible unsafe replay or required production/provider/deployment action lacking authority. Stop the affected unsafe action; stop the *entire run* only when no independent safe work can proceed or the blocker cannot be contained. Report exact scope and necessary owner decision.

Existing source authority, player agency, privacy, consent, Daggerheart truth and receipt integrity are established protections, not newly proposed narrative censorship.
