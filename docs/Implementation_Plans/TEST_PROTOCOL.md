# Fresh, changed-code-only test protocol

**Absolute for this initiative:** Never run, import, copy, modify/re-enable, migrate or repurpose any existing `bot/scripts/*-test.mjs`, historical fixture, golden output, old suite launcher, `npm run validate`, `validate:extended`, `npm test`, or legacy workflow. Preserve historical files as archaeology only; do not delete production legacy readers needed for persisted compatibility.

**NO TEST WATCHING OR POLLING:** [TEST_EXECUTION_NO_POLL.md](TEST_EXECUTION_NO_POLL.md) governs the execution lifecycle. Start a batch once, use one blocking call with an adequate timeout or a detached runner while doing independent work, and collect one final result only at a natural milestone. Never repeatedly inspect process/session status or stream live output. A running test is not a passed test.

Create new Node tests under `bot/tests/ai-gm-2026-10/`, named by feature ID. Tests must import only currently modified production modules plus Node standard libraries and brand-new feature-local fakes. Use temporary disposable SQLite storage, injected deterministic dice/clock, mocked provider and Discord; zero network/prod DB by default. One feature batch after completing source and fixture authoring, then batched repairs. Run `node --check` only on changed JS/MJS and `node --test tests/ai-gm-2026-10/<feature>.test.mjs` from `bot/`. If a changed shared module affects several codepaths, write a new focused cross-boundary test scoped to those changed contracts; never route to old suites. Final gate executes union of freshly written tests covering **only production code modified in the initiative**.

To adopt CI, create a new opt-in workflow and selector, which must demonstrably exclude inherited validation. Existing repository workflow is historical; changing or disabling it requires explicit review, not a silent weakening of security. Record exact SHA, command, test count, exit code, skipped/failed cases and input/test hashes. A passing delta is not full product qualification, real Discord proof or a release certificate.
