## Global and resource sensitivity

Module-level `WeakMap` grant/flight registries, cached content/catalogs and provider objects are enumerated as module state or call candidates. Moving or duplicating such a module can create two registries and invalidate opaque authority. Preserve single module identity until explicit injected ownership and fresh tests replace it. In particular, cached native catalog/content state and opening single-flight maps are not substitutes for durable SQLite claims.

`content.js`, `content-packages.js`, rule/catalog loaders, `GMService` construction, `db.js` schema reads, entrypoints and supported export/cost CLIs require resource-path review. The graph flags `import.meta.url`, environment access and top-level initializers. Lexical candidates do not prove effects absent; nested/deferred callbacks and object aliases need the relevant migration's manual review.
