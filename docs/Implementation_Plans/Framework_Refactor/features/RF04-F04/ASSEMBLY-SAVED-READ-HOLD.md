# Assembly writer brief saved-read compatibility

`bot/src/assembly-context.js` is Session-owned and directly imports `openingWorldOpportunities` from the Session–World pair source `opening-world-bridge.js`; the corresponding `FRAMEWORK_IMPORTS_PAIR` transition remains open. Replacing that import with a port bound only by application startup would alter an existing read path: `assemblyWriterBrief` calls the bridge before consulting a scene, and with no active session the bridge returns its empty, non-authoritative opportunity structure. For a public brief with no selected contract, the remainder of the reader can return without startup composition. An unbound fixed port would throw before that fallback.

This is a source-based compatibility finding, not an executed runtime failure or a phase-wide blocker. Preserve the original public reader and its no-active-session behavior. A future migration needs a single authoritative implementation that stays available to the saved read without a new startup dependency, and a fresh changed-code regression covering both pre-bootstrap empty public briefs and composed source-authorized opportunities. Do not duplicate the fallback or add a transition exception. RF04 remains open; RELEASE NOT AUTHORIZED.
