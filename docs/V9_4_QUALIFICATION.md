## Native NPC Fear move contract and rollback

`npc_attack` context references an already prepared `pc_incoming_attack`, not free text or a simulation action. Its immutable GM-reviewed offer uses the exact version-2 attacker Fear authorization as source, the current scene/session and a damage-profile participant as target. It remains character-private. Selection must precede dice; a completed unrelated attack cannot be adopted. Before RNG and before a new HP effect, the selected decision, context, trigger, native source, gate, owner and scope are revalidated. Native attack/defense/damage/Armor services still own all mechanics.

Fear remains `move_selected` while native defense/dice/Armor are pending; `NATIVE_EFFECT_PENDING` is an expected status, not a waiver or failed scene. After a verified native hit/damage or miss, a separate Fear accounting receipt records the saved native references and completes that one obligation. It never replays NPC dice/HP. Failed accounting writes roll back only that accounting transaction; separately committed native damage survives and the same selection can retry. Read-side revocation quarantines the effect part and preserves unrelated native output. No raw NPC description becomes PC agency.

Persistence is additive context/effect data on existing records, no SQL migration or old-history rewrite. Rollback must hold unfamiliar `npc_attack` contexts and preserve all saved NPC/PvP dice, HP, Armor, ownership and choices. Never downgrade to generic resource events, reset campaign memory, or satisfy Fear with a fictional replacement. Retracted-source/principal/scene recovery remains explicit reviewed work; general durable recovery is V9-03.

The official [Daggerheart SRD 2.0](https://www.daggerheart.com/wp-content/uploads/2026/08/DH_SRD_2_2026_08_25.pdf), GM action rolls (PDF page 86), was rechecked: NPC attacks use d20 + attack modifier against Evasion; natural 20 auto-succeeds and adds the maximum damage dice, not twice the flat modifier. No NPC metacurrency or extra Duality dice were introduced. Tests supply deterministic entropy solely inside temporary offline fixtures; production dice and saved receipts remain native.

Actual executed counts, exits and commit SHAs belong in `TYPED_INTENT_PROGRESS.md`; this document does not infer a pass from coverage names. No production access, bot, command registration, model endpoint or deployment is authorized.
