# AI-Assisted Character Concept Wizard — v3.2.0

Players no longer need to understand every Veiled City/Daggerheart option before joining.

## Draft from prose

Use:

`/vc character concept description:<plain-English concept>`

Veilkeeper uses only player-safe campaign material and creates a **Level 1 draft**. The draft preserves the player's concept over optimization and includes class/subclass, ancestry/community, two domains, Level 1 trait spread, two Experiences, starting cards, equipment suggestions, and structured campaign hooks.

The draft is not a character until approved.

Review it with:

`/vc character concept-status`

Accept it with:

`/vc character concept-accept`

If the draft needs changes, simply run `/vc character concept` again with the revised description. The most recent pending draft is used.

## Hook permissions

Every proposed background hook is classified as one of:

- **Established** — the player's description makes this true.
- **Open Question** — the answer is deliberately left to future GM/play.
- **Permission to Complicate** — a player-created person/place/obligation may be developed by the GM without deciding an unrelated hidden truth.

Veilkeeper must not invent hidden mystery answers merely to complete character creation.

## Mechanical validation

The application validates the Level 1 trait spread, class/domain access, Veiled City custom-domain substitution, Experience count, domain-card count, and hook classifications. If official card/resource metadata is not available in the bundled player-safe reference, Veilkeeper flags it rather than claiming unsupported certainty.
