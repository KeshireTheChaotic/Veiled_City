## v3.2.0 — Campaign Integrity & Character Lifecycle

- Added `/vc-character concept`: create Level 1 drafts from plain-English concepts with structured **Established / Open Question / Permission to Complicate** hooks.
- Added validated `/vc-character level-*` advancement with tier achievements, advancement limits, domain-card eligibility, and automatic pre-level snapshots.
- Added deterministic combat state for adversary HP, Stress, thresholds, conditions/effects, defeated/escaped status, GM Fear, and advisory spotlight tracking.
- Duality rolls now apply Hope/Fear/Critical resources automatically; `reaction:true` avoids Hope/Fear and spotlight changes.
- Added `/vc-admin snapshot`, `snapshots`, and `rollback`, plus automatic snapshots around sessions and major state changes.
- Added a versioned canon ledger; contradictions create GM-resolved conflicts instead of silently replacing established facts.
- Added between-session downtime projects/world turns with public/private results, clocks, and state consequences.
- Rules answers now identify **RAW / Veiled City House Rule / Homebrew / GM Ruling / Provisional**, with saved human-GM rulings taking precedence.
- Existing v3.1.3 campaigns migrate additively; no new Discord channels or permissions are required.
