# R3 — durable source-qualified Spellcast roll identity

Implementation slice complete. All R0–R8 acceptance gates remain incomplete.

Extended openRollAdjudications with optional native catalog/canonical-actor dependencies and an optional Spellcast locator on save. The locator is validated against the actual owned active packaged domain card, explicit printed Spellcast clause and subclass trait. Its binding, classification hash and actor control revision commit atomically with the unchanged closed accepted-decision shape. Read requalifies current card/subclass/owner/control, checks the adjudication hash and returns only the four-field binding needed by native modifier inspection. Normal trait-value changes do not redefine roll identity; they remain current roll-term evidence. No activation, cost, dice, consequence, GM approval or publication authority is created by this storage API.

Identity and decision are immutable together. An existing ordinary adjudication cannot gain a classification in place, and exact replay of a classified adjudication cannot omit its identity. Missing configured native sources or stale identity hold rather than trust persisted labels. No model-facing capability, prose classifier or generic state patch was added. The native caller's check remains responsible for actual adjudication authority; source authentication alone is not GM approval.
