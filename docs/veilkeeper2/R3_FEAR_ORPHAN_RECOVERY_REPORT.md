# R3 — reviewed orphan-hold recovery (slice complete)

Added native `recoverUnreserved` to the Fear store and coordinator. It only handles an exact saved hold with no reservation. It requires inspected approved recovery evidence bound to campaign/request/decision and a named reviewer, plus matching native publication evidence with no attempt. Evidence is reread before commit. The store writes a cancellation tombstone in the same transaction domain used by reservation creation, preventing a late reservation from reviving the abandoned interruption. An existing real reservation cannot use this path.

The coordinator saves that receipt before releasing the roll hold through the existing matching-cancellation validator. A failure between those steps leaves the roll held and can resume after reopening. Replay preserves the original review and receipt. There is no arbitrary unlock, Fear spend, attack completion or model-exposed tool.
