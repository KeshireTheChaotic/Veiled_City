# R3 — atomic native Hope cost

Implemented a dedicated opt-in Hope rule transaction. Amount and owner confirmation come from native cost evidence loaded by reference; no arbitrary patch or model amount API is exposed. The transaction compares the actor resource revision, validates permanent cap/available Hope, and writes the changed pool and immutable receipt together. Identical evidence replay returns the original receipt without spending again. Changed evidence, wrong owner, insufficient Hope and stale revisions fail. Native evidence is reread before commit and authorization is checked at both transaction boundaries.
