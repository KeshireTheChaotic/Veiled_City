# R3/R6 — reviewed atomic PC bootstrap (slice complete)

Added one fixed native initialization operation that copies exact marked HP/Armor, Stress, Hope, permanent Hope cap and level into canonical defenses/Hope/lifecycle tables in a single action-store transaction. It accepts a closed native character snapshot and an exact source-bound human-GM review from trusted native readers. It is not a resource patch, character import, PC choice, restoration or model tool. Existing/partial rows cannot be overwritten or silently completed. An immutable typed bootstrap receipt preserves the original source/review and initial state; replay returns it without resetting later gameplay changes.

The accompanying native source reader loads an existing registered owner PC and the native character repository, verifies campaign/owner/control/status and derives the snapshot from persisted sheet fields. It requires explicit pool values/permanent cap and hashes the full native character/control source for lineage. Prepared import/export labels are not this repository. GM-private sheet content is not copied into the mechanical bootstrap receipt. Missing or historical death state, final HP, zero permanent slots and incomplete source/review remain migration holds rather than healthy defaults. Active/reserve/guest native sheets may initialize only when existing registered owner control is active.
