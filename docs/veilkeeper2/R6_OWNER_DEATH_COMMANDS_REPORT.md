# R3/R6 — authenticated owner death command gateway (slice complete)

Added an opt-in command gateway for the existing `/vc-roll effect` and `/vc roll effect` aliases. Exact `death-review` requests with the new runtime's `incoming-death:` reference present the private native controls; they do not accept risks or select a move. Exact `death-reconcile` requests check an original native component interaction through the fixed receipt repair path. These are native commands, not AI capabilities or prose classifiers. Other legacy references/operations and natural speech pass through unchanged.

The same-client observed slash event supplies identity. Native target ownership, PC owner control, canonical identity/control revision, active scene/session, current attendance, provisioned command channel and a trusted actor-scoped route are required. Neither player JSON nor GM/admin status can supply another owner or control grant. The gateway privately defers before asynchronous permission refresh, compares the complete fresh native audience with the provisioned channel, and rechecks identity/session scope across the workflow. A command from a provisioned party channel still sends controls only through the owner-private workflow route. Command text is never inserted as PC dialogue or sent to AI.

Native interaction storage gains a closed `discord_command` binding variant, rather than pretending a slash event is a delivered component message. It stores command identity/hash and scope, not raw JSON. Claims prevent repeated command processing or confirmation after duplicate events/reopening. Native completed presentation/reconciliation and reply uncertainty remain separate. Deferred failures receive a generic private hold where possible; initial unobserved/unauthorized calls reject before claiming or acknowledging, so a consuming command router must catch those errors privately. Observation alone executes nothing: the future root router must await `handle` and consume a handled route before any legacy dispatcher. This module is not installed alongside the old production handler.
