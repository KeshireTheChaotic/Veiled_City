# Rules References Used During Design
**Visibility: PLAYER SAFE**

Veiled City v2.0 was designed against the Daggerheart SRD 2.0 rules baseline and the official Daggerheart Homebrew Kit. The package does not reproduce the full core rules; use the official SRD as rules authority.

- Daggerheart SRD: https://www.daggerheart.com/srd/
- Daggerheart Homebrew Kit: https://www.daggerheart.com/homebrewkit/
- Daggerheart Downloads: https://www.daggerheart.com/downloads/

Design notes used from official guidance include: streamlined card text, 21-card domain structure, asymmetric PC/adversary mechanics, class HP/Evasion balance principles, tier benchmark adversary statistics, environment structure, and equipment feature budgeting.

This is unofficial homebrew for private play and does not use official Daggerheart logos.
