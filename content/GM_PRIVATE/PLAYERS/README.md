# GM-Private Character Narrative Markdown

This directory is the standard package path for **GM-only freeform character narrative** that does not fit structured JSON, GM hook records, or the canon ledger.

Naming convention:

`GM_PRIVATE/PLAYERS/GM_PRIVATE_<Character_Name>.md`

Import with `/vc-character narrative-import scope:gm_private` or attach it to `/vc-character import-gm-hooks`. Export with `/vc-character narrative-export scope:gm_private|all`.

GM-private Markdown is available to Veilkeeper as secret context and must not be revealed until discovered in play. Structured JSON controls mechanics/resources; the canon ledger remains authoritative for durable world truth.
